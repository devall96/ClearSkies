Clear Skies

Cemu's Clarity, back in Hyrule.

An add-on for Savage Wind Recomp that brings over Cemu's Clarity look with all 20 presets: less haze, less blown-out bloom, richer colour. Not a single Savage Wind file is changed.

Newest version: see the release page

What Clarity looks like

Serfrost's preset, Clarity's recommended look. Nineteen more ship with it, from Filmic to Survival of the Wild, and all 65 of Clarity's settings can be tuned on top.

Pick a look, press Play

A small launcher starts Savage Wind with Clarity switched on for that one run. To try another preset, choose it and press Play again.

  • 20 presets, 65 settingsEvery preset from Cemu's pack, and every Clarity setting adjustable on top, with the same names as in Cemu.
  • Your game stays untouchedClear Skies runs as a Vulkan layer for the game it starts, and only replaces one shader on its way to your graphics card.

Coming: a full mod manager

In the works · not in the download yet

Clear Skies is growing into a mod manager for Breath of the Wild on Savage Wind, for the mods that can't go into Savage Wind itself. This is the plan; follow along on GitHub.

  • Your mods in one listDrop a mod's .zip, .7z, .rar or folder on the window, tick the ones you want and put them in order.
  • Any layoutA Switch romfs folder, Atmosphère's layout, a BCML export or the bare files, with DLC files put where they belong.
  • Clear about conflictsSee which mods change the same files and which one wins, and which mods can't work, with the reason.
  • GameBanana built inBrowse, search and look at mods without leaving Clear Skies, then download and install one in a click, checked against GameBanana's MD5.
  • Preset savesInstall a 100% save or one from a certain point. Your own saves are backed up first, and any backup can be put back.
  • Pack mergingTwo mods that change the same pack get merged together, instead of one replacing the other.
  • Bigger files that loadThe game's resource size table is adjusted for you, so mods that make files bigger just work.
  • Wii U mods on SwitchWii U mods and Cemu graphic packs converted to the Switch's byte order, so the game can read them.
  • Never touches the gameMods are merged when you press Play, through Savage Wind's own overlay. Start the game directly and it's unmodded.
  • Updates itselfAn Update button when there's a new Clear Skies, checked against GitHub's checksum, keeping your settings and mods.

Download Clear Skies

Windows

Windows 10 or 11, 64-bit, with a Vulkan graphics card
Download Clear SkiesClearSkies-<version>.zip
  1. Unzip the ClearSkies folder anywhere. Its files must stay together.
  2. Run ClearSkies.exe. If Windows says "Windows protected your PC" (Clear Skies isn't code-signed), click More info → Run anyway.
  3. Choose a look, click Browse to find your savagewind.exe, and press Play.
  4. For a new version, download it here again and unzip it over the old folder.
Before you start
  • A working Savage Wind. Set up with your own game files and started at least once. Savage Wind Recomp isn't included.
  • Precompiled shaders, for the smoothest first run: Precompile shaders in Savage Wind Configuration.
  • Nothing to uninstall. Delete the folder and it's gone. Start savagewind.exe directly any time for the original look.
